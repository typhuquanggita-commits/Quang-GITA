# Ấn Gen Việt — tệp gốc

Năm tệp trong thư mục này là **bản sinh ra** từ `tools/sinh-thuonghieu.cjs`.
Không sửa tay. Cần đổi thì sửa toạ độ trong bộ sinh rồi chạy lại:

```bash
node genviet365/tools/sinh-thuonghieu.cjs
```

| Tệp | Dùng khi nào |
|---|---|
| `an-gen-viet-lam.svg` | bản thường ngày · lam GITA |
| `an-gen-viet-son.svg` | bản nghi lễ · đỏ son |
| `an-gen-viet-muc.svg` | bản một nét · mực |
| `an-gen-viet-dao.svg` | bản đảo · trắng trên nền đặc |
| `an-gen-viet-theo-mau-chu.svg` | ăn theo màu chữ nơi nhúng |

Luật dùng ấn, vùng an toàn và tám cách dùng sai: xem tập 7,
`docs/GEN_VIET_365_THUONG_HIEU.md`, mục A3.
