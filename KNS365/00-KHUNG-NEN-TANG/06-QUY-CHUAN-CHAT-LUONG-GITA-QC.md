# BỘ QUY CHUẨN CHẤT LƯỢNG **GITA-QC**
### 40 tiêu chí kiểm định một buổi huấn luyện KNSGITA

**Cách dùng:** Quan sát viên (Tổ trưởng chuyên môn / Giám sát học vụ) chấm trực tiếp trong buổi học. Mỗi tiêu chí chấm **0 – Không có · 1 – Có nhưng chưa đủ · 2 – Đạt đủ**. Tổng tối đa **80 điểm**.

| Xếp loại buổi học | Điểm | Hành động |
|---|:--:|---|
| **Xuất sắc – chuẩn mẫu** | ≥ 72 | Ghi hình làm học liệu mẫu toàn hệ thống |
| **Đạt chuẩn** | 64 – 71 | Ghi nhận, góp ý 1–2 điểm |
| **Cần cải thiện** | 48 – 63 | Kèm cặp, dự giờ lại trong 30 ngày |
| **Chưa đạt** | < 48 | Tạm dừng đứng lớp độc lập, đào tạo lại |

> **Tiêu chí phủ quyết (Veto):** Nếu **bất kỳ** tiêu chí nào trong nhóm **A (An toàn)** bị chấm 0, buổi học **tự động xếp loại Chưa đạt** bất kể tổng điểm.

|:--:|---|:-:|:-:|:-:|
| A1 | Không gian, dụng cụ, hoạt động thể chất được kiểm tra an toàn trước giờ học | | | |
| A2 | Học sinh được thông báo và thực sự có **quyền "pass"** trong mọi hoạt động chạm cảm xúc cá nhân | | | |
| A3 | Không có ngôn ngữ hạ nhục, mỉa mai, so sánh tiêu cực giữa học sinh | | | |
| A4 | Thông tin cá nhân/câu chuyện riêng tư của HS được bảo mật, không bị chia sẻ ra ngoài | | | |
| A5 | HLV nhận diện và xử lý đúng quy trình khi có dấu hiệu HS bị tổn thương/nguy cơ | | | |
| A6 | Hoạt động phù hợp lứa tuổi, không gây áp lực tâm lý quá ngưỡng, không kỳ thị | | | |

## NHÓM G – GOAL *(8 tiêu chí)*

| # | Tiêu chí | 0 | 1 | 2 |
|:--:|---|:-:|:-:|:-:|
| G1 | Đích buổi học được **công bố rõ ràng** trong 20 phút đầu | | | |
| G2 | Công bố **đủ 2 vạch**: mức ĐẠT và mức XUẤT SẮC | | | |
| G3 | **100% học sinh viết Thẻ Đích cá nhân** (không phải chép mục tiêu của giáo viên) | | | |
| G4 | Mục tiêu viết theo chuẩn **SMART-E**, có động từ hành vi đo được | | | |
| G5 | HLV **nối được đích buổi lên đích năm/đích đời** ít nhất 1 lần trong buổi | | | |
| G6 | Tiêu chí thành công (rubric) được **treo/phát cho HS trước khi làm**, không phải sau khi chấm | | | |
| G7 | Có hoạt động **đo điểm xuất phát** (thang tự tin/bài kiểm tra nhanh đầu buổi) | | | |
| G8 | Cuối buổi HS **tự đối chiếu** kết quả với đích đã đặt | | | |

## NHÓM I – INSPIRITS *(8 tiêu chí)*

| # | Tiêu chí | 0 | 1 | 2 |
|:--:|---|:-:|:-:|:-:|
| I1 | Có **cú chạm cảm xúc mở màn** (câu chuyện/trải nghiệm/con số) khiến HS muốn tham gia | | | |
| I2 | Có hoạt động chạm **Lửa 3 – Nội lực** (ý nghĩa, danh tính, phụng sự), không dừng ở Lửa 1 | | | |
| I3 | HS được nói về **khát khao/mong muốn của chính mình** ít nhất 1 lần | | | |
| I4 | HLV xử lý ít nhất 1 **niềm tin giới hạn** xuất hiện trong buổi (kỹ thuật Belief Flip) | | | |
| I5 | Mỗi HS ghi được **≥1 dòng Nhật ký Bằng Chứng** trong buổi | | | |
| I6 | Có hoạt động **vượt vùng an toàn có kiểm soát** phù hợp lứa tuổi | | | |
| I7 | **Sự khác biệt cá nhân được gọi tên tích cực**, không bị san phẳng | | | |
| I8 | Không khí lớp: HS **dám sai, dám hỏi, dám thử** – quan sát được qua số lần HS chủ động phát biểu | | | |

## NHÓM T – TALENT *(9 tiêu chí)*

| # | Tiêu chí | 0 | 1 | 2 |
|:--:|---|:-:|:-:|:-:|
| T1 | Có **mẫu chuẩn + phản mẫu** (làm đúng và làm sai cố ý) để HS so sánh | | | |
| T2 | Kỹ năng được **tách thành 3–5 vi kỹ năng** đo được, không dạy chung chung | | | |
| T3 | **T-DRILL chạy ≥3 vòng** trong buổi | | | |
| T4 | **100% HS thực hành ≥3 lượt** – không có học sinh chỉ ngồi xem | | | |
| T5 | Phản hồi theo đúng công thức **1-1-1** (1 điều đúng – 1 điều chỉnh – làm lại ngay) | | | |
| T6 | **Mỗi HS nhận ≥2 phản hồi cá nhân** trong buổi (có bảng theo dõi lượt) | | | |
| T7 | Có **nâng bậc độ khó** rõ rệt theo GITA Ladder trong buổi (ít nhất L→L+1) | | | |
| T8 | Có ghi nhận **số liệu luyện tập** (thời gian, số lượt, điểm rubric), không chỉ nhận xét cảm tính | | | |
| T9 | **Điểm mạnh/mũi nhọn cá nhân** của ít nhất 3 HS được chỉ ra đích danh và cụ thể | | | |

| N7 | Có yếu tố **thi đua lành mạnh** (đấu trường/thử thách nhóm) đúng 4 luật đạo đức | | | |
| N8 | Có **nghi thức ghi nhận** cuối buổi (mỗi HS ghi nhận 1 bạn) | | | |

## NHÓM V – VẬN HÀNH & SƯ PHẠM CHUNG *(9 tiêu chí)*

| # | Tiêu chí | 0 | 1 | 2 |
|:--:|---|:-:|:-:|:-:|
| V1 | Bám đúng **khung 7 phân đoạn / 180 phút**, sai lệch mỗi phân đoạn ≤5 phút | | | |
| V2 | Đạt **quy tắc 30-30-40** (HLV nói ≤30%, HS thực hành ≥40%) | | | |
| V3 | Chuẩn bị đầy đủ **dụng cụ theo kit** ghi trong giáo án, không thiếu vật tư | | | |
| V4 | **Phiếu thực hành & phiếu đánh giá** đúng mã, đủ số lượng, thu về đủ | | | |
| V5 | **Phân hoá**: có nhiệm vụ dành cho HS nhanh (L4–L5) và hỗ trợ cho HS chậm | | | |
| V6 | Quản lý lớp bằng **nghi thức và tín hiệu**, không bằng quát tháo | | | |
| V7 | **Giải lao đúng lịch**, có vận động, HS được uống nước/vệ sinh | | | |
| V8 | **Hồ sơ buổi học** được hoàn tất trong 24 giờ (điểm danh, quan sát, ảnh sản phẩm) | | | |
| V9 | Có **phản hồi gửi phụ huynh** trong 48 giờ sau buổi 2 của chuyên đề | | | |
